# Kingmaker

Assistant de draft League of Legends : les meilleurs picks et bans pour ta partie, calculés sur des centaines de milliers de parties Émeraude+, avec leurs raisons.

**[Télécharger pour Windows](https://github.com/olympio171/KingMaker/releases/latest/download/Kingmaker-Setup.exe)** · [Site](https://olympio171.github.io/KingMaker/)

Ce dépôt héberge le site et les versions de l'app (l'app installée se met à jour toute seule). Le modèle du moment est publié dans la version « model ».
